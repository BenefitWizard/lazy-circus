# How to Extract Template Haskell Generated Code

This guide explains how to see the exact Haskell code generated by Template Haskell macros (like `makeServiceLib`) in this project.

## The Approach

To view the spliced code generated by Template Haskell at compile time, you need to pass the `-ddump-splices` flag to the GHC compiler. 

### Using cabal

```bash
cabal clean && cabal build --ghc-options="-ddump-splices" 2>&1 | tee th_dump.txt
```

### Using stack

```bash
stack clean && stack build --ghc-options="-ddump-splices" > th_dump.txt 2>&1
```

*(Note: `clean` is recommended to force the compiler to re-process and re-generate the TH splices for modules that might already be cached/compiled).*

## Extracting the Clean Code

The compiler output in `th_dump.txt` will contain a lot of build information, warnings, and the actual TH splices wrapped in a specific formatting.

Look for lines that look like this:

```text
common/SimpleServiceLib.hs:(31,1)-(48,5): Splicing declarations
    makeServiceLib
      ...
  ======>
    data AllServices
      = AllServices ...
```

The actual generated code starts directly after the `======>` marker and ends when the compiler outputs the next warnings or file compilations.

### Quick Python Script for Cleanup

You can use a script similar to this to extract and format just the generated code for a specific file dump:

```python
with open("th_dump.txt", "r") as f:
    text = f.read()

# Select the part after the splice marker
start = text.find("======>")
if start != -1:
    text = text[start + 7:]

# Cut off before the next GHC diagnostic or module compilation
end = text.find("common/SimpleServiceLib.hs:")
if end != -1:
    text = text[:end]

# Remove the default 4-space indentation GHC adds to dumped splices
lines = text.split("\n")
cleaned = [l[4:] if len(l) > 4 and l.startswith("    ") else l for l in lines]

with open("GeneratedCode.hs", "w") as f:
    f.write("\n".join(cleaned).strip() + "\n")
```
