## Reviewer Output

### Summary

The tool description threading is architecturally sound — `ToolDescription` flows through the `Script` GADT into `local`-scoped environment updates, and the `HasToolDescriptions` constraint on `runAI` correctly forces every call site to provide the capability. The Template Haskell layer generates a complete tool infrastructure (enum, ToolCall/ToolResponse, FromJSON dispatch, executeToolCall, smart constructors).

### Issues Found and Fixed

#### Critical — Silent wrong dispatch on duplicate tool-name strings

**Location:** `src/LazyCircus/App/Service/TH.hs`, `makeServiceLib`

**Problem:** `makeServiceLib` validated enum constructor Names for uniqueness but never checked that the tool-name strings (second element of each spec triple) were unique across all request types. If two specs had the same tool-name string, the generated `FromJSON ToolCall` instance would silently select the first match, causing wrong dispatch.

**Fix:** Added `detectDuplicateToolNameStrings` validator called in `makeServiceLib` alongside `detectDuplicateEnumConstructors`.

**Status:** ✅ Fixed

---

#### High — Generated code depends on splice-site imports

**Location:** `src/LazyCircus/App/Service/TH.hs`, multiple generators

**Problem:** TH generators used `mkName` for external library names (Data.Aeson, LazyCircus.Script, LazyCircus.Scene.AI.Lang). Names created with `mkName` resolve at the splice site, requiring users to independently import Data.Aeson.

**Fix:** Added direct imports of `Data.Aeson`, `LazyCircus.Scene.AI.Lang`, and `LazyCircus.Script` to the TH module. Converted all relevant `mkName` calls to quoted names (`''FromJSON`, `'withObject`, `'AIScriptDef`, etc.).

**Status:** ✅ Fixed

---

#### High — No duplicate field-name validation

**Location:** `src/LazyCircus/App/Service/TH.hs`, `makeServiceLib`

**Problem:** Two request types from different modules with the same base name would produce duplicate record field names, leading to confusing compile errors.

**Fix:** Added `detectDuplicateFieldNames` validator called after `detectDuplicates` in `makeServiceLib`.

**Status:** ✅ Fixed
